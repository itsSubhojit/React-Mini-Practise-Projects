# React Mini Practice Projects

A collection of small React projects built to practice core frontend concepts such as state management, hooks, UI handling, and API integration.

---

## 📂 Project Structure (Example)

```bash
react-mini-practice-projects/
│
├── 02counter
├── 03tailwindprops
├── 04bgchanger
├── ...
```

Each folder represents an independent mini project focused on a specific concept.

---

## 🚀 Overview

These projects are built as part of a learning process to improve understanding of React and modern frontend development by creating small, focused applications.

---

## 🛠 Tech Stack

* React.js
* JavaScript (ES6+)
* Vite
* Tailwind CSS

---

## ▶️ Getting Started

```bash
git clone https://github.com/itsSubhojit/react-mini-practice-projects.git
cd project-folder-name
npm install
npm run dev
```
