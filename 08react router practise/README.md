# React Router Practice 🚀

## Overview

A practice project to learn **React Router** and implement client-side navigation in a React application.

## Key Learnings

* Routing with `BrowserRouter`, `Routes`, `Route`
* Navigation using `Link` and `NavLink`
* Nested routes with `Outlet`

* Completed an additional footer task independently
