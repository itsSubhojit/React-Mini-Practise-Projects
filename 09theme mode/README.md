# Theme Mode (Light/Dark) 🌗

## Overview

A React project to implement **light and dark theme switching** using Context API and Tailwind CSS.

## Key Concepts

* Context API (`createContext`, `useContext`)
* Global state management
* Dark mode with Tailwind (`class` strategy)
* useEffect for DOM updates

## Work Done

* Implemented theme toggle (light ↔ dark)
* Managed global theme state using Context API
* Applied theme by updating `html` class dynamically
* Followed tutorial and implemented logic step-by-step
